# VentureVaults — TEST CLONE

Isolated shared-space experiment. Original Pilot-Portfolio is unchanged.

Two copies of the original orbital world share one camera and starfield. Each has independently cloned records, scoped IDs, its own orbit rings, black hole and connections. World 2 is flagged. Click either world label to focus it; use Fit to see both.

Source baseline: Pilot-Portfolio commit 497ad258a90c6673b0b66794d9e3bd704e2f574d.

## Run

npm ci
npm run dev

## Build

npm run check
npm run build

For a static frontend deployment: build command `npm run build`, output `dist/public`.

This is a visual/data-isolation prototype with duplicated sample content. User accounts, persistent separate vaults, arbitrary 2D/3D world imports and multi-user permissions are not implemented.
